Privacy Policy

Last updated: 2026-11-18

  • What we access: With the user's permission, the Tool receives a TikTok access token and refresh token, and basic profile information (user.info.basic). It uses the video.upload scope only to send the user's own videos to the user's TikTok inbox as drafts.
  • Where it is stored: Tokens are stored only on the user's own computer. No server, database, or third party receives them.
  • Sharing: No data is sold, shared, or used for advertising or analytics.
  • Deletion: The user can delete the local token file at any time and revoke access in TikTok settings (Security and permissions > Apps and services).
  • Contact: Via the GitHub account that hosts this page.

プライバシーポリシー（日本語）

本ツールは、本人の許可を得て TikTok のアクセストークンと基本プロフィール情報を受け取り、video.upload の権限で本人の動画を本人の受信箱に下書きとして送るためだけに使います。トークンは本人のパソコンの中だけに保存し、サーバーや第三者には送りません。データの販売・共有・広告や分析への利用はしません。トークンのファイルはいつでも削除でき、TikTok の設定（セキュリティと権限 > アプリとサービス）から連携を解除できます。
